---
title: Review prepared resumes
description: Review the exact PDF, saved posting, questions and source changes from your preparation queue.
---

Open **Applications → Queue → Ready for review**, then choose **Review resume**. The review workspace keeps the prepared PDF beside the saved job description, with preparation notes and any recorded requirement gaps above it. **Previous resume** and **Next resume** move through the prepared jobs on the current queue page.

For a LaTeX resume, the PDF is compiled from its saved source version through the authenticated server compiler. The workspace checks that the draft still belongs to this job and has not changed while the PDF is prepared. **Download reviewed PDF** downloads the same PDF shown in the preview. Use **Refresh current draft** after editing; a stale or differently linked draft cannot silently replace the displayed version.

Check the rendered page for readable type, spacing and clipping. Expand **Extracted PDF text** to inspect reading order and missing characters. Page count and overflow diagnostics help identify problems; missing checks remain unverified. Ordinary structured resumes use the existing PDF export renderer and do not show LaTeX compiler diagnostics.

Expand **Changes from source resume** to see actual saved-source changes. The default comparison uses the source resume's current saved content. It does not establish what the source contained when the copy was created, and it does not verify factual claims. Your supplied Google Doc remains the authoritative background record.

Use **Edit resume** for corrections and **Open original application** to continue applying. Opening this workspace, downloading a PDF or moving to the next resume never marks an application Applied. Confirm the attached document and employer's submission confirmation before recording the application as submitted.
